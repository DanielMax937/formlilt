# PDF fonts

SIL Open Font License 1.1 (see OFL.txt). Embedded as subsets containing the used glyphs; never fetched from a third party during filling.

- [Noto Sans regular](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans)
- [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF) — static TrueType instance at weight 400, built with fonttools 4.65.0; see OFL-CJK.txt — includes Chinese, Japanese and Korean glyphs.
- [Noto Sans Arabic regular](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansArabic)

Mixed scripts must be covered by the selected font. Unsupported characters produce a readable field error rather than silently dropping glyphs.
